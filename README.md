# 心意闯关 · 心意实验室

甜美粉色风格的情侣互动闯关网页原型。

## 当前功能

- 创作中心：编辑标题、寄语、关卡名称、价格、提示和内容。
- 心意实验室：神秘礼物、心动选择题、剧情分支、隐藏关卡灵感。
- 体验中心：逐关模拟解锁、进度显示和最终惊喜。
- 本地保存：使用浏览器 localStorage。
- V2 分享：将文字配置打包进专属 URL hash；支持 JSON 导入/导出。

## 当前限制

- 解锁仅为模拟，不会扣款。
- 分享链接仅携带文本配置，不包含照片/音频/视频文件。
- 当前无云端数据库、账号系统、媒体上传、微信支付或支付宝真实收款。
- 分享链接需要先成功部署到 HTTPS 页面后才能跨设备访问。

## 启用网页部署（一次性设置）

1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 的 Source 中选择 **GitHub Actions**。
3. 保存后打开 Actions，等待 **Deploy Heart Lab preview** 工作流成功。
4. 成功后页面地址应为：

   https://905695129-art.github.io/-2/

本仓库的部署工作流位于 `.github/workflows/deploy.yml`，监听 `heart-lab-v1` 分支的页面文件更新。

## 本地预览

直接用浏览器打开 `index.html`。本地文件模式下不会生成可跨设备访问的分享链接。
