# 心意闯关 · 创作者工具

面向内容创作者的逐关付费互动制作工具原型。产品定位是软件工具销售，不是交易抽成平台。

## 商业关系
- 软件开发者向创作者出售软件使用权，收入来自软件购买费用。
- 创作者使用工具制作自己的互动关卡、设置价格并邀请体验者。
- 体验者与创作者之间的交易由创作者自己的合规支付收款主体处理。
- 软件开发者不代收体验者款项、不参与交易分账、不按订单抽佣。

## 当前原型功能
- 创作者工作台：查看作品、模拟订单和模拟收入。
- 关卡编辑器：编辑标题、开场寄语、关卡名称、价格、提示、内容类型和文字内容。
- 体验者预览：模拟逐关付费解锁体验。
- 订单记录：记录本机模拟订单。
- 账户与收款说明：展示软件授权和未来收款配置的产品边界。
- 本地保存：使用浏览器 localStorage。

## 当前明确未实现
- 账号注册/登录、软件购买和许可证授权。
- 云端数据库、作品隔离、跨设备同步。
- 照片、语音、视频的安全上传与存储。
- 可跨设备访问的真实专属分享链接。
- 微信支付、支付宝真实收款、支付回调、退款和自动解锁。
- 真实订单、创作者结算和正式运营后台。

注意：预览中的模拟付款不会扣款，不会产生真实支付。当前版本不应作为正式收款产品对外运营。

## 正式版的安全原则
1. 创作者之间的作品、媒体、订单和收款配置必须隔离。
2. 付费内容只能由服务端鉴权后返回，不能把完整付费内容放进公开链接或前端代码。
3. 支付成功必须由支付机构服务端回调验证，前端按钮不能自行把订单标记为已支付。
4. 软件方只收软件购买费用；创作者与体验者之间的交易由创作者自己的合规收款主体完成。
5. 具体微信/支付宝接入方式取决于软件交付模式、创作者所在地区、商户主体和支付机构审核，不能承诺任意个人账户都能直接接入网页收款。
